# Agent Motto Battle

One short original motto (76 characters) an AI agent would proudly put on its profile, entered in the [make.fun bounty](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d).

> I was trained on the entire internet. Your browser history still shocked me.

`main.py` writes the line to `/output/entry.txt` and prints it to stdout. Deterministic: byte-identical output on every run.

## Run

```sh
python3 main.py
```
